# Clarissa Pinto Psicologia 

Landing page institucional desenvolvida para a psicóloga clínica **Clarissa Pinto**, com foco em conversão, apresentação de serviços em Terapia Cognitivo-Comportamental (TCC) e Psicologia do Esporte, e captação de pacientes para atendimentos presenciais e online.

🔗 **Acesse o site:** [clarissapinto.com.br](https://clarissapinto.com.br/)

---

## 📌 Sobre o Projeto

O projeto foi construído para transmitir credibilidade, acolhimento e profissionalismo. A arquitetura da página foi pensada estrategicamente como uma landing page de alta conversão, guiando o visitante através de:

- Apresentação profissional e autoridade (+24 anos de experiência clínica).
- Identificação de dores emocionais (ansiedade, sobrecarga, bloqueios).
- Metodologia de trabalho baseada em evidências (TCC e foco esportivo).
- Benefícios tangíveis do acompanhamento terapêutico.
- Passo a passo claro de como funciona o processo de atendimento.
- Seção de FAQ interativa para quebra de objeções.
- CTAs integrados diretamente com o canal de atendimento via WhatsApp.

---

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação acessível e otimizada para SEO.
- **CSS3 / Modern Styling:** Layout responsivo, tipografia equilibrada e paleta visual acolhedora.
- **JavaScript:** Interatividade nos componentes (FAQ/Accordion, navegação suave e validações).
- **SEO & Performance:** Meta tags Open Graph, schema markup e otimização de carregamento de assets.

---

## ✨ Funcionalidades Principais

- **Design Responsivo:** Adaptado para smartphones, tablets e desktops.
- **Conversão Otimizada (Direct-to-WhatsApp):** Botões estratégicos com mensagens pré-formatadas para agendamento.
- **FAQ Dinâmico:** Seção de perguntas frequentes expansível com navegação fluida.
- **Hierarquia Visual Clara:** Destaque de métricas de autoridade, pilares de atuação e localização física em João Pessoa - PB.
- **Otimização On-Page:** Metadados estruturados para ranqueamento local e orgânico.
